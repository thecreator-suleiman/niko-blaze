Privacy Policy – Niko Blaze Publisher

Niko Blaze Publisher is a private tool used only by the owner of the Niko Blaze YouTube channel to upload the channel's own music videos.

It uses the YouTube Data API only to upload videos, set titles, descriptions, thumbnails and read basic statistics for that one channel. It does not collect, sell or share data about any other person. OAuth tokens are stored as encrypted GitHub Actions secrets and can be revoked at any time at myaccount.google.com/permissions.

This tool uses YouTube API Services. See the YouTube Terms of Service and Google Privacy Policy.
