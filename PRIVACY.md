# Niko Blaze Publisher — Privacy Policy

_Last updated: 23 November 2026_

Niko Blaze Publisher is a private, internal tool operated by Kwizera Selemani (contact: afrosuleiman@gmail.com).
It publishes original music by the artist Niko Blaze to the owner's own YouTube channel
(https://www.youtube.com/@nikoblazeofficial) using YouTube API Services.

**Who uses it:** only the channel owner. It has no other users and no sign-up.

**What data it accesses:** only the owner's own YouTube channel, through an OAuth authorization given by the owner.
It uploads the owner's videos, sets their thumbnails and reads basic information (video IDs, titles, publishing
status) about the owner's own uploads to confirm publishing.

**What it does not do:** it does not access, collect, store, sell or share any data of other YouTube users or
viewers, and does not act on any other channel.

**Storage:** the only stored data is the owner's OAuth refresh token (kept as an encrypted GitHub Actions secret)
and a private log of the owner's own uploads. It is never shared with third parties.

**Revoking access:** the owner can revoke access at any time at https://myaccount.google.com/permissions.

**Google and YouTube:** this tool uses YouTube API Services. See the YouTube Terms of Service
(https://www.youtube.com/t/terms) and the Google Privacy Policy (https://policies.google.com/privacy).
